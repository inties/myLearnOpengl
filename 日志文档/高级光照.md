### blinn-phong



​	如前所述，Phong 模型在反射方向  与视线  角度大于 90 度时，镜面高光强度会降为零，这在现实中不准确（例如，低光泽度表面可能仍会反射一些光）。Blinn-Phong 模型通过半程向量避免了这个问题，因为半程向量的方向更稳定，即使视点的角度变化较大，半程向量变化更平滑，镜面高光不会突然消失。

这在处理动态场景或相机视角大幅变化时尤为重要，避免了高光闪烁或不连续的问题。



### gamma校正

​	为了让图像在显示时看起来自然，图像数据在存储或渲染之前需要进行“Gamma校正”，通过预先调整信号来抵消显示设备的非线性效应。



#### 用法

​	使用gamma校正可以直接开启，也可以在着色器中使用

1.

```
glEnable(GL_FRAMEBUFFER_SRGB);
```



2.

```
void main()
{
    // do super fancy lighting 
    [...]
    // apply gamma correction
    float gamma = 2.2;
    fragColor.rgb = pow(fragColor.rgb, vec3(1.0/gamma));
}
```

​	如果你有很多像素着色器，它们可能分别用于不同物体，那么你就必须在每个着色器里都加上gamma校正了。一个更简单的方案是在你的渲染循环中引入**后处理阶段**，对screenshader的输出使用gamma校正，这样你只要做一次就好了。



​	对漫反射贴图进行重校：

```
glTexImage2D(GL_TEXTURE_2D, 0, GL_SRGB, width, height, 0, GL_RGB, GL_UNSIGNED_BYTE, image);
```

##### 剔除正面以消除自遮挡

​	剔除正面（glCullFace(GL_FRONT)）能解决阴影悬浮问题，因为它改变了深度贴图的参考平面，从最靠近光源的**正面切换到背面**，利用模型的几何厚度自动引入深度间隔，避免了深度比较时的精度误差。这种方法比手动调整偏置更自然，尤其适合封闭模型。恢复剔除背面（glCullFace(GL_BACK)）则是为了确保后续渲染的正确性。

在这一节中，实现了法线贴图。我们使用的法线贴图定义在切线空间中。使用TBN矩阵的逆矩阵，将光照、顶点、摄像机等变换到切线空间中，来计算光照。



#### 原理

什么是切线空间

在法线贴图的上下文中，切线空间是一个局部坐标系，定义在模型表面的每个顶点或像素处。它由三个互相垂直的向量组成：

- **切向量（Tangent Vector, T）**：沿着表面纹理坐标（如UV坐标）的U方向，通常表示水平方向。
- **副切向量（Bitangent Vector, B，或 Binormal）**：沿着表面纹理坐标的V方向，通常表示垂直方向。
- **法向量（Normal Vector, N）**：垂直于表面的方向，表示表面的朝向。



**TBN矩阵**：

- 从模型的顶点数据中计算切向量T和法向量N（副切向量B可以通过T和N的叉乘得到：B = N × T）。
- 这些向量组成一个3x3的TBN矩阵，用于将切线空间中的法线转换到世界空间或视角空间。

```
 mat3 TBN = transpose(mat3(T, B, N));//将TBN矩阵求逆（正交矩阵等价于求转置）
 
 //将世界坐标空间中的点转换到切线空间中，在切线空间中计算光照
    vs_out.TangentLightPos = TBN * lightPos;
    vs_out.TangentViewPos  = TBN * viewPos;
    vs_out.TangentFragPos  = TBN * vec3(model * vec4(position, 0.0));
```

### HDR

​	high dynamic range。可以理解为通过一个tone map函数，动态调整亮度范围，

​	为了能够扩宽光照强度的范围，避免超过1的光被clamp成1，引入tone map，在计算出光照后，将其映射到[0,1]。

​	选择不同的tone map算法以及参数，可以凸显对不同亮度范围。例如，让暗处的光线范围在映射后占比较大，能够更好地显示暗处的细节，较亮的部分映射后占比大，能够显示出亮处的细节。前者相当于一个低曝光度的相机，后者相当于一个高曝的相机。可以动态调整曝光度。
